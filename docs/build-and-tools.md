# Build And Tool Commands

Run commands from the repository root unless a section says otherwise.

```bash
cd /path/to/Voloxide
```

## Prerequisites

### Rust

Install Rust with `rustup`, then add the embedded targets used by the board crates:

```bash
rustup target add thumbv8m.main-none-eabihf
rustup target add thumbv7em-none-eabihf
```

### probe-rs

Install `probe-rs` for hardware flashing and debug-probe access:

```bash
cargo install probe-rs-tools
```

### ROSflight Simulation

For the ROSflight simulator path, source ROS 2 and the ROSflight workspace before running Voloxide
shim commands. Voloxide scripts intentionally do not source ROSflight helper scripts.

Example:

```bash
source /opt/ros/jazzy/setup.zsh
source /path/to/rosflight/workspace/install/setup.zsh
```

The tested Voloxide integration does not require edits to `rosflight_io` or generated ROSflight
install files.

## xtask

`xtask` is the repository command wrapper. It keeps common commands discoverable and avoids long
target/package invocations.

```bash
cargo xtask <command>
```

| Command | What it does |
| --- | --- |
| `cargo xtask check-host` | Runs `cargo check` for host-compatible default workspace members. |
| `cargo xtask test-host` | Runs core and simulator library tests. |
| `cargo xtask check-board pico2w` | Checks Pico 2 W firmware for `thumbv8m.main-none-eabihf`. |
| `cargo xtask check-board nucleo` | Checks Nucleo firmware for `thumbv7em-none-eabihf`. |
| `cargo xtask check-board pixracerpro` | Checks Pixracer Pro firmware for `thumbv7em-none-eabihf`. |
| `cargo xtask build-board <board>` | Builds the selected board's `voloxide` binary. |
| `cargo xtask flash-board <board>` | Runs the selected board's `voloxide` binary through Cargo's runner. |
| `cargo xtask build-sim-lib` | Builds `target/debug/libsim.a` for the ROS 2 shim. |
| `cargo xtask clean-generated` | Removes ignored build/runtime artifacts generated by local runs. |

Supported board names:

```text
pico2w
nucleo
pixracerpro
```

## Host Checks

```bash
cargo xtask check-host
cargo xtask test-host
```

Direct equivalents:

```bash
cargo check
cargo test -p voloxide_core
cargo test -p sim --lib
```

## Board Checks

```bash
cargo xtask check-board pico2w
cargo xtask check-board nucleo
cargo xtask check-board pixracerpro
```

Direct equivalents:

```bash
cargo check -p pico2w --target thumbv8m.main-none-eabihf
cargo check -p nucleo --target thumbv7em-none-eabihf
cargo check -p pixracerpro --target thumbv7em-none-eabihf
```

## Board Builds And Flashing

Build:

```bash
cargo xtask build-board pico2w
cargo xtask build-board nucleo
cargo xtask build-board pixracerpro
```

Flash/run through the configured Cargo runner:

```bash
cargo xtask flash-board pico2w
cargo xtask flash-board nucleo
cargo xtask flash-board pixracerpro
```

The board crates own their runner configuration. For RP2350 work in this branch, flashing has also
been done with explicit `probe-rs` commands during hardware bring-up. See
[RP2350 / Pico 2 W guide](boards/rp2350-pico2w.md).

## ROS 2 Shim Build

The build/source helper is:

```bash
source scripts/build_and_source_ros2_shim.zsh
```

It runs:

```bash
cargo xtask build-sim-lib
colcon build --base-paths sim/ros2/voloxide_sil_board_shim ...
source workspace/install/setup.zsh
```

Generated outputs:

```text
target/debug/libsim.a
workspace/build/
workspace/install/
workspace/log/
```

Run the full tested simulator workflow from:

[Voloxide ROScopter sim end-to-end](tutorials/voloxide-roscopter-sim-end-to-end.md)

## Generated Cleanup

Remove local generated artifacts:

```bash
cargo xtask clean-generated
```

This removes:

```text
target/
workspace/
rosflight_memory/
tools/__pycache__/
tools/espnow_uart_bridge/build*/
tools/espnow_uart_bridge/sdkconfig
tools/espnow_uart_bridge/dependencies.lock
```

After cleanup, rebuild the ROS 2 shim with:

```bash
source scripts/build_and_source_ros2_shim.zsh
```

## ESP32C5 ESP-NOW UART Bridge

The ESP32C5 bridge lives outside the Rust workspace:

```text
tools/espnow_uart_bridge/
```

It is an ESP-IDF project. Role-specific default configs are checked in:

```text
sdkconfig.air.defaults
sdkconfig.ground.defaults
sdkconfig.stats.defaults
sdkconfig.test-pattern.defaults
```

See the bridge guide:

[ESP32C5 ESP-NOW UART bridge](../tools/espnow_uart_bridge/README.md)
